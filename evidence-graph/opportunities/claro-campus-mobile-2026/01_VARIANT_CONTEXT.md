# Variant Context — EvidentGraph Mobile

## Relationship to the Core

EvidentGraph Mobile is not a second unrelated project.

It is a **vertical application** of the EvidentGraph Core for mobile-oriented digital systems.

Core hypothesis:
- fuse metadata, code/contracts, authorization, lineage, and runtime evidence.

Campus Mobile application:
- apply that evidence fusion to mobile apps and the backend/API/agent ecosystem that supports them.

## Mobile-oriented problem framing

Modern mobile services may depend on:

Mobile App  
→ API Gateway  
→ API / Service  
→ Database / Data Platform  
→ MCP / AI Agent / Model

A change, permission, or agent action can affect a mobile user even when the dependency is not obvious from the app itself.

## Variant questions

### CAN IT?
Can an AI agent, mobile backend, or identity reach sensitive data used by the mobile service?

### DID IT?
Was that access actually observed in runtime?

### WHAT BREAKS?
If an API/schema/tool used by the mobile service changes, what mobile journeys, agents, or services may be affected?

## Key constraint

The mobile component must be meaningful, not decorative.

A generic corporate dashboard merely viewed on a phone would be a weak fit.

The variant should demonstrate a genuine mobile use case such as:
- mobile incident response;
- mobile app/API dependency intelligence;
- alerts and impact analysis for mobile operations;
- governance of agents interacting with mobile-service data/APIs.
