# Competitive Landscape

## Core conclusion

The broad category already exists. EvidentGraph must not be positioned as “the first graph connecting data, APIs, and AI agents.”

### Data / context graph
- DataHub
- Atlan
- Collibra
- Informatica

### Agent / AI governance
- Holistic AI
- Credo AI
- IBM watsonx.governance

### API / AI gateway
- Sensedia
- other API/MCP gateways

### Native data/AI governance
- Databricks Unity Catalog + Unity Gateway
- Snowflake and other platform-native governance stacks

## Current whitespace hypothesis

The research opportunity is narrower:

**cross-control-plane evidence fusion**

Correlate what different systems say about the same dependency:
- declared;
- code-derived;
- authorized;
- lineage-derived;
- runtime-observed.

Then explicitly preserve agreement, disagreement, uncertainty, and freshness.

## Strategic posture

Incumbents may become integrations rather than only competitors.

Examples:
- Databricks can supply lineage, governance, permissions, MCP/agent metadata, and AI activity.
- Sensedia can supply API/MCP identity and runtime evidence.
- GitHub/OpenAPI can supply code/contract evidence.
- OpenTelemetry can supply observed execution.

## Rule

Every competitor claim should be re-verified before external publication because these products evolve quickly.
