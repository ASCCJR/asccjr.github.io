# Name & Positioning

## Working name

# EvidentGraph

### Descriptive subtitle

**Dependency Intelligence for Data, Software & AI**

### Portuguese description

**Grafo de evidências para dependências de dados, software e IA.**

## One-line hypothesis

EvidentGraph correlates metadata, code/contracts, authorization, lineage, and runtime evidence to explain what can reach a resource, what actually did, and what may break when something changes.

## What the name does not imply

EvidentGraph is not:
- a graph database product;
- only a data lineage tool;
- only an agent-governance product;
- a Databricks replacement;
- a generic observability platform.

The graph is the representation. The intended value is **evidence-aware dependency intelligence**.

## Naming status

The name is provisional and can change before commercialization or public launch. A future startup phase would require trademark, company-name, domain, and product-name checks.
