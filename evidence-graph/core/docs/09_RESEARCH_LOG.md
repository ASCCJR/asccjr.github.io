## R-001 — Broad cross-domain graph is already an active market
**Status:** fact from competitive research

DataHub, Atlan, Collibra, Holistic AI, Sensedia, Databricks, and adjacent security/governance vendors already cover significant portions of data, software, API, and agent governance.

**Implication:** the broad graph itself is not sufficient novelty.

---

## R-002 — Evidence fusion is the narrower research hypothesis
**Status:** hypothesis

Potential contribution: preserve and correlate declared, static, authorization, lineage, and runtime evidence instead of collapsing them into one dependency relation.

**Questions:**
- does this improve precision/recall?
- does it reveal hidden dependencies?
- does it improve blast-radius prioritization?
- can disagreement itself become useful evidence?

---

## R-003 — Agentic AI is a strong demonstration domain
**Status:** product/research framing decision

Agents make the dependency problem tangible because they combine identities, tools, MCPs, APIs, models, and data.

**Important:** agentic AI is a flagship use case, not a restriction of the Core.

---

## R-004 — Databricks is both benchmark and possible connector
**Date:** 2026-09-25
**Status:** verified against public Databricks materials

Unity Catalog + Unity Gateway cover substantial parts of data + AI governance, including agents, MCP services, lineage, access control, and runtime policies.

Databricks should not be treated as a system that only governs assets built natively inside it.

**Implication:** treat Databricks as both overlap/competition and a high-value future evidence source.

See: `10_DATABRICKS_STRATEGIC_NOTE.md`.
