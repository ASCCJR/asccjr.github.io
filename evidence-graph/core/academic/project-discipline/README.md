# Disciplina de Projetos — workspace

## Decision

Yes: **EvidentGraph Core will be the project used in the discipline.**

This is useful because the discipline asks for the creation/development of a project, while EvidentGraph already has:

- a problem;
- a research question;
- a proposed solution;
- state-of-the-art research;
- a synthetic MVP;
- technical hypotheses;
- a roadmap;
- possible users and value propositions.

## Rule

Course activities use the Core as their source.

If an activity introduces a useful insight, it can later be promoted into the canonical Core through a decision/research update.

The course itself must not silently redefine the project.

## Workflow for each class activity

1. Save the exact activity/question in `ACTIVITY_LOG.md`.
2. Answer it using the current Core.
3. Mark any new assumptions as hypotheses.
4. After feedback from the professor/class, record what changed.
5. Promote durable changes to the Core only when justified.
