## Atualização manual a partir do currículo-base

O repositório privado `ASCCJR/Curriculo` reúne os fatos profissionais e os currículos para candidaturas. Este repositório reúne o currículo público, a vitrine e os estudos de caso. Em 24/11/2026, Antonio decidiu manter a atualização manual entre os dois.

Ao atualizar uma informação destinada ao site, revise os trechos correspondentes em `index.html`, em `portfolio/index.html` e na página do projeto. Use o currículo-base como referência dos fatos e preserve o idioma, o layout e a seleção editorial dessas páginas. As publicações seguem a autorização de Antonio e devem ser conferidas na versão no ar.
